# 操作手册

从零到出成品中文 PPT 的完整流程。日常只需要**第 3 节**那一条命令。

环境已在本机配好：Ollama 在 `D:\Ollama`，模型 `hy-mt-local` 已注册，服务监听
`http://localhost:11434`。下面命令一律在 `D:\AI-tools` 目录执行。

---

## 0. 先确认 Python 依赖（只做一次）

本机有两个 Python，注意区分：

| 解释器 | 路径 | python-pptx |
| --- | --- | --- |
| 你的默认 `python` | `...\Programs\Python\Python312\python.exe` | ✅ 已装 |
| DSH 运行时 | `...\.dsh\dsh-runtimes\...\python\python.exe` | ✅ 已装 |

如果换机器、或报 **`ModuleNotFoundError: No module named 'pptx'`**，装一次即可：

```powershell
python -m pip install python-pptx opencc-python-reimplemented
```

- `python-pptx`：读写 pptx（**必需**）
- `opencc-python-reimplemented`：繁→简转换（建议装；不装则用内置小表兜底）

验证：

```powershell
python -c "import pptx; print('python-pptx', pptx.__version__)"
```

## 2. 开机后 / 每次开工前：启动服务

**Ollama 不会自己启动**（本机没配任何自启），关机重启后需要你手动开一次。
启动一次即可，之后它一直挂着，直到你关机或手动停掉。

### 方式 A：双击（最省事）

打开资源管理器，进 `D:\AI-tools\scripts`，**双击 `start_ollama.cmd`**

黑窗口一闪，出现这样几行就成功了：

```
正在启动 Ollama ...
  OLLAMA_MODELS = D:\Ollama\Models
  已启动 (PID 32096)

服务已就绪: {"version":"0.40.3"}
  NAME                  ID              SIZE      MODIFIED
  hy-mt-local:latest    5dc922bab85c    1.1 GB    24 hours ago
```

约 **12 秒**（要等 GPU 初始化）。窗口会自动关闭，服务留在后台。

### 方式 B：敲命令

```powershell
powershell -File D:\AI-tools\scripts\start_ollama.ps1
```

### 方式 C：手动两步（不想用脚本）

先设模型目录，**再**启动。顺序不能反：

```powershell
$env:OLLAMA_MODELS = "D:\Ollama\Models"      # 必须先设，否则找不到模型
Start-Process "D:\Ollama\ollama.exe" -ArgumentList "serve" -WindowStyle Hidden
```

> ⚠️ **为什么必须先设 `OLLAMA_MODELS`**：`ollama serve` 没有命令行参数，
> 模型目录**完全靠这个环境变量**。不设的话 Ollama 会去
> `C:\Users\Administrator\.ollama\models` 找，那里是空的，于是每次都报
> `model not found`——尽管你的权重好好躺在 `D:\Ollama\Models`。

### 确认是否在跑

```powershell
curl.exe -s http://localhost:11434/api/version
```

有 `{"version":"0.40.3"}` 就是好的。或者看详细状态：

```powershell
powershell -File D:\AI-tools\scripts\start_ollama.ps1 -Status
```

```
服务状态 : 运行中  {"version":"0.40.3"}
程序     : D:\Ollama\ollama.exe  (存在)
模型目录 : D:\Ollama\Models
           1080.6 MB
已注册模型: hy-mt-local:latest
环境变量 : OLLAMA_MODELS(User) = D:\Ollama\Models
```

### 重复启动没关系

服务已在运行时再执行一次，脚本会说"已经在运行，不需要重复启动"并直接退出，
**不会**起出第二个进程。

### 想停止服务

```powershell
Get-Process ollama | Stop-Process -Force
```

正常用不着——它占的内存很小（空闲约 50 MB），重启电脑自然就没了。

### 想让它开机自动启动

本机**故意没配**自启（你要求手动启动）。如果以后想改成自动，把下面这段发给
维护者即可，或用任务计划程序添加一个"登录时"触发的任务，执行：

```
powershell.exe -NoProfile -WindowStyle Hidden -ExecutionPolicy Bypass -File "D:\AI-tools\scripts\start_ollama.ps1"
```

## 3. 翻译 PPT（日常主命令）

```powershell
cd D:\AI-tools
python -m pptx_translate "D:\课件\1 -LLM PENTEST.pptx" `
    --provider ollama --ollama-model hy-mt-local
```

产出：`D:\课件\1 -LLM PENTEST.zh-CN.pptx`（默认在源文件旁边，文件名加 `.zh-CN`）。

想指定输出位置就加 `-o`：

```powershell
python -m pptx_translate "D:\课件\deck.pptx" -o "D:\出稿\deck-中文.pptx" `
    --provider ollama --ollama-model hy-mt-local
```

**速度参考**（RTX 3050，1.8B Q4_K_M）：约 **2.3 秒/段**。77 页 / 446 段 ≈ **17 分钟**。
带翻译记忆（缓存），中断后重跑只补没翻的；全部命中时重跑只要 **6 秒**。

## 5. 常用场景

### 先看清单，不翻译

```powershell
python -m pptx_translate "deck.pptx" --dry-run
```

列出页数、段数、字符数，以及前 40 条原文。

### 导出原文 / 用现成译文

```powershell
python -m pptx_translate "deck.pptx" --dump-strings strings.json   # 导出
python -m pptx_translate "deck.pptx" --strings-json zh.json        # 用你人工翻好的
```

### 统一术语（推荐做一次）

术语表是**硬锁定**：命中的词在发出去之前就被替换成占位符，模型根本没机会翻错。

```powershell
# glossary.csv 每行 "英文,中文"
# Rules of Engagement,交战规则
# prompt injection,提示注入
python -m pptx_translate "deck.pptx" `
    --provider ollama --ollama-model hy-mt-local `
    --glossary glossary.csv
```

内置表已锁 23 个专有名词（LLM、OWASP、MITRE ATT&CK、CVE…）保持英文。
`--no-glossary` 可关闭。

### 中文变长导致溢出

默认 `--autofit off`：**只翻译，绝不动字号**。先看有多少框会溢出：

```powershell
python -m pptx_translate "deck.pptx" --autofit-preview
python -m pptx_translate "deck.pptx" --autofit no-titles   # 正文缩放，标题保持
```

### 顺带翻译演讲者备注

```powershell
python -m pptx_translate "deck.pptx" --notes
```

### 不联网自检（不调模型，验证整条流程）

```powershell
python -m pptx_translate "deck.pptx" --provider mock
```

## 6. 翻译完必做：结构校验

报告会自动生成在输出旁边（`<输出>.report.json`）。更严格的逐形状比对：

```powershell
python scripts\verify_pptx.py "原文件.pptx" "译后文件.pptx"
```

期望输出（三项都必须是 0）：

```
shape-set differences : 0
geometry differences  : 0
style differences     : 0
media identical: True
```

### 交付前质检

```powershell
python scripts\final_qa.py "译后文件.pptx" "译后文件.report.json"
```

检查：占位符残留（应为 0）、段落对齐（源/译段数一致）、手动换行结构。

## 8. 常见问题

| 现象 | 原因 / 解决 |
| --- | --- |
| `ModuleNotFoundError: No module named 'pptx'` | 这个 Python 没装依赖 → `python -m pip install python-pptx opencc-python-reimplemented`（见第 0 节） |
| `connection refused` 10061 | 服务没起来 → `Start-Process "D:\Ollama\ollama.exe" -ArgumentList serve` |
| `model 'hy-mt-local' not found` | 没注册 → `cd D:\AI-tools\Models; ollama create hy-mt-local -f Modelfile` |
| `ollama` 命令不认识 | PATH 没刷新 → 新开终端，或 `$env:Path = "D:\Ollama;" + $env:Path` |
| 报告显示"未翻译"很多 | 服务或模型有问题；先跑第 4 节冒烟测试 |
| 术语用词不统一 | 写 `--glossary` 硬锁定（第 5 节） |
| 想重翻全部 | 删掉 `<输出>.cache.json`，或加 `--no-cache` |
| 中文被截断 | `--autofit-preview` 先看，再 `--autofit no-titles` |
| 想更快 | 1.8B 已是最快的可用翻译模型；7B 更准但慢 3~4 倍 |
| 不想在被翻译的目录里留报告 | 加 `--report D:\某处\report.json`；报告默认写在输出文件旁边 |

## 9. 换模型

```powershell
# 列出已注册模型
ollama list

# 用别的模型翻译
python -m pptx_translate "deck.pptx" --provider ollama --ollama-model <模型名>
```

想换成质量更高的 7B：

```powershell
curl.exe -L --retry 12 --continue-at - `
  --output D:\AI-tools\Models\Hunyuan-MT-7B-Q4_K_M.gguf `
  https://hf-mirror.com/mradermacher/Hunyuan-MT-7B-GGUF/resolve/main/Hunyuan-MT-7B.Q4_K_M.gguf

cd D:\AI-tools\Models
@'
FROM ./Hunyuan-MT-7B-Q4_K_M.gguf
PARAMETER temperature 0
PARAMETER num_predict 512
PARAMETER num_ctx 4096
'@ | Set-Content -Encoding UTF8 Modelfile-7b
ollama create hy-mt-7b -f Modelfile-7b
```

之后加 `--ollama-model hy-mt-7b` 即可，代码不用改。

## 10. 云接口用法（备份方案）

本地模型不够好、或想用更大模型时：

```powershell
# 环境变量读 Key，不要写进命令行
$env:DEEPSEEK_API_KEY = "sk-xxxx"
python -m pptx_translate "deck.pptx" --provider deepseek

# 任意 OpenAI 兼容接口
python -m pptx_translate "deck.pptx" --provider openai `
  --base-url "https://api.example.com/v1/chat/completions" --model "your-model"
```

Key 读取顺序：`DSH_TRANSLATE_API_KEY` → `DEEPSEEK_API_KEY` → `TOKENHUB_API_KEY`
→ `SILICONFLOW_API_KEY` → `OPENAI_API_KEY`。指向 `localhost` 的地址自动免密钥。

## 全参数速查

```powershell
python -m pptx_translate --help
```

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `input` | 必填 | 源 `.pptx` / `.pptm` |
| `-o, --output` | `<名字>.zh-CN.pptx` | 输出路径 |
| `--provider` | `deepseek` | `ollama` / `local` / `deepseek` / `openai` / `mock` |
| `--ollama-model` | `hy-mt-local` | Ollama 模型名 |
| `--ollama-host` | `http://localhost:11434/v1` | Ollama 地址 |
| `--glossary` | 内置 23 项 | 硬锁定术语（JSON 或 `源,译` 每行） |
| `--no-glossary` | 关 | 不锁定任何术语 |
| `--autofit` | `off` | `off` / `no-titles` / `all` |
| `--autofit-preview` | 关 | 只报告溢出，不改字号 |
| `--notes` | 关 | 同时翻译备注 |
| `--cache` / `--no-cache` | `<输出>.cache.json` | 翻译记忆，失败不写入 |
| `--dry-run` | 关 | 只列清单 |
| `--dump-strings` | 无 | 导出全部原文 |
| `--strings-json` | 无 | 用现成译文，完全不调模型 |
| `--report` | `<输出>.report.json` | 报告路径 |
| `-v` / `-q` | 中 | 详细 / 安静 |
